你好呀，旅人！欢迎降落在这个梦幻紫的小宇宙 🌌

这里是**星梦**的个人小站，用来存放代码笔记、追番碎碎念和一些不切实际的梦。
站点用 [Astro](https://astro.build) 从零搭建，参考了 Fuwari 主题的布局，
再撒了一点樱花和一只看板娘进去。

## 这个站点有什么

- 🌸 **樱花飘落**与**看板娘**特效（都可以在配置里开关）
- 🌙 明暗双主题，跟随系统偏好，也能手动切换
- 🔍 大圆角卡片 + OKLCH 梦幻紫配色，柔和但有精神
- 📝 完整的 Markdown 支持：目录、代码高亮、表格、引用……
- 📡 RSS 全文订阅，随时用阅读器追更

## Markdown 写起来是什么感觉

### 代码块

支持明暗两套代码配色（拿铁 / 摩卡），写技术笔记很舒服：

```ts
// 每一片花瓣都是自己画出来的喵～
const petal = (hue: number) => `hsla(${hue}, 85%, 82%, 0.8)`;

export function greet(name: string): string {
  return `こんにちは、${name}！欢迎来到星梦小筑 ✦`;
}
```

> —— 就像开源世界那样 *闪闪发光* 呢 ✨

行内代码 `const dream = true`、**加粗**、*斜体*、~~删除线~~ 和
[链接](https://astro.build) 都能正常工作。

## 开始写作

在 `src/content/posts/` 下新建一个 `.md` 文件，复制任意一篇现有文章的
frontmatter 改一改，就是一篇新文章了。文件名就是文章链接，比如
`hello-world.md` → `/posts/hello-world`。

写完记得 `pnpm build` 检查一下，然后就发布吧！🚀
